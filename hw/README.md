# hw/

FPGA sources. Every Vivado project here is generated by a script, so the
`vivado/` folders are disposable and not versioned.

| Folder | |
|---|---|
| [`multitx/`](multitx) | the MultiTX platform: [`create_project.tcl`](multitx/create_project.tcl), the block design [`system_bd.tcl`](multitx/system_bd.tcl), [`system_top.v`](multitx/system_top.v), constraints (`pins.xdc` from the reference design, `timing.xdc`) |
| [`ip/usb_debug_bridge/`](ip/usb_debug_bridge) | USB → AXI4-Lite bridge over the FX3. `usb_cmd_proc.v` is the command processor, `ettus/` the reused GPIF II code, `tb/` its testbenches |
| [`ip/adc_capture/`](ip/adc_capture) | AD9361 sample capture into block RAM, readable over AXI |
| [`ip/gfsk_tx/`](ip/gfsk_tx) | packet GFSK/FSK modulator with a channel NCO; `tb/check.py` simulates it and demodulates the output |
| [`ip/tcxo_dac/`](ip/tcxo_dac) | Ettus' auto-SPI shifter for the TCXO tuning DAC |
| [`ref_b220/`](ref_b220) | the f4tnk v20e reference design rebuilt in Vivado 2022.2 from the `reference/` submodule (sources referenced in place, IP cores recreated in `ips.tcl`) |

```bash
source /opt/AMD/2022.2/Vivado/2022.2/settings64.sh
vivado -mode batch -source hw/multitx/create_project.tcl -tclargs build   # MultiTX
vivado -mode batch -source hw/ref_b220/create_project.tcl -tclargs build  # reference
```

The design is described in [docs/architecture.md](../docs/architecture.md).
